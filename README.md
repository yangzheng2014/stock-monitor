# 股票监控（Stock Monitor）

轻量 · 免费 · 同花顺风格的本地股票监控工具。单文件 Flask 应用，深色主题，数据来自免费公开接口，无需任何付费 API。

## 功能特性

- **K 线蜡烛图**：ECharts 渲染，支持悬停明细、滚轮缩放、拖拽平移
- **双均线叠加**：MA5 / MA20 自动计算，最新值实时显示
- **三档时间区间**：20 日 / 50 日 / 200 日一键切换
- **实时行情刷新**：交易时段 5 秒轮询，自动更新最后一根 K 线；午间休市/收盘/休市日自动降频
- **多源自动容灾**：东方财富 → 腾讯 → 新浪三级数据源，任一失败自动降级，来源可溯源
- **股票搜索**：按代码或名称（拼音首字母）搜索，支持键盘上下选择 + 回车确认
- **涨跌停大框**：右侧实时展示当日涨停 / 跌停股票池（名称、代码、涨跌幅、连板数），点击列表项直接切换监控标的
- **涨跌停价格**：面板头部按板块规则（ST ±5%、创业板/科创板 ±20%、主板 ±10%）自动计算，触板高亮
- **非交易日兜底**：涨跌停池自动回退到最近交易日数据，日期明确标注
- **本地缓存**：K 线数据落盘缓存，二次打开秒加载
- **数据校验**：创业板/科创板 20% 涨跌停容差校验，过滤异常行情

## 快速开始

```bash
# 1. 创建虚拟环境（Python 3.11+）
python3 -m venv .venv

# 2. 安装依赖（已配置清华 PyPI 镜像源，~/.pip/pip.conf）
.venv/bin/pip install -r requirements.txt

# 3. 启动（默认监控三环集团 sz300408，端口 8765）
.venv/bin/python main_v0.2.3.py

# 常用参数
.venv/bin/python main_v0.2.3.py 600519          # 启动即监控贵州茅台
.venv/bin/python main_v0.2.3.py -p 9000         # 指定端口
.venv/bin/python main_v0.2.3.py --no-browser    # 不自动打开浏览器
```

浏览器访问 `http://127.0.0.1:8765/`。

## 数据源

| 数据 | 来源 |
|------|------|
| K 线（主） | 东方财富 push2his（前复权） |
| K 线（备） | 腾讯 fqkline / 新浪 getKLineData |
| 实时行情 | 东方财富 → 新浪 → 腾讯 |
| 涨跌停池 | 东方财富 push2ex 涨停池/跌停池 |

均为免费公开接口，行情数据仅供参考，不构成投资建议。
